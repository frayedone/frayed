# frayed

> Личное расписание колледжа: пары, тренировки, пересдачи, погода и транспорт Алматы.

**Репозиторий:** https://github.com/frayedone/frayed

Одно пользовательское приложение без аккаунтов, входа и облачной синхронизации. Все настройки,
правки расписания, пресеты групп и кеши хранятся локально на устройстве. Сборки публикуются
через GitHub Releases и устанавливаются прямо из приложения.

## Возможности

- Недельное расписание: пары, перерывы, лабораторные, тесты и тренировки.
- Редактирование занятий, отмена дня, пресеты групп.
- Локальные уведомления: утренняя сводка и напоминания о ближайшей паре.
- Погода Алматы через Open-Meteo и подсказка «пора выходить» с учётом погоды и следующей пары.
- Транспорт: статические маршруты и ориентировочное прибытие по остановкам рядом с колледжем.
- Проверка обновлений через GitHub Releases, скачивание APK и установка.

## Архитектура

Приложение написано на Rust. Вся доменная логика и состояние находятся в Rust-крейтах;
Android-обвязка сведена к тонкому JNI-слою для локальных уведомлений и установки APK.

| Крейт | Назначение |
| --- | --- |
| `frayed-core` | Расписание, отмены дней, пресеты групп, тема, даты, погода и подсказки, SemVer, локальное хранилище |
| `frayed-net` | Open-Meteo, GitHub Releases, транспорт Алматы |
| `frayed-ui` | Slint-разметка, регистрация шрифта Base 02, окно приложения |
| `frayed-app` | Точка входа Android (`cdylib`), JNI-хуки для уведомлений и установки APK |

### Стек

- **Rust** (edition 2021) — вся логика.
- **Slint 1.19** — нативный UI на Rust, Android-бэкенд `backend-android-activity-06`.
- **cargo-apk2** — сборка release APK.
- **GitHub Actions** — публикация релизов.

### Шрифты

Заголовки и названия экранов используют `Base 02 Cyrillic` (`assets/fonts/Base-02-Cyrillic.ttf` и
`Base-02-Cyrillic-Bold.ttf`). Оба файла встраиваются в бинарник через `include_bytes!` и
регистрируются в Slint до создания окна. Для заголовков указана цепочка
`"Base 02", "Roboto", sans-serif`. Основной текст использует системный sans-serif с полной
поддержкой кириллицы.

## Сборка локально

Нужны Rust, Android SDK (platform 35, build-tools 35.0.0), NDK 27.2.12479018 и JDK 17.

```bash
rustup target add aarch64-linux-android
cargo install cargo-apk2@1.5.0 --locked
cargo apk2 build -p frayed-app --lib --release --target aarch64-linux-android
```

Проверка без Android SDK:

```bash
cargo test --workspace
cargo check -p frayed-app
```

APK появится в `target/`. Для подписи release-сборки добавьте свой keystore и настройте его
в `crates/app/Cargo.toml` (файлы `*.keystore` в репозиторий не попадают).

## Релизы и обновления

Workflow `.github/workflows/release.yml` запускается по тегу `v*` или вручную (`workflow_dispatch`):

1. Устанавливает JDK 17, Android SDK и NDK.
2. Собирает release APK для `aarch64-linux-android`.
3. Переименовывает артефакт в `frayed-<версия>.apk`.
4. Публикует его в GitHub Releases репозитория `frayedone/frayed` с автоматическими release notes.

Приложение запрашивает `/releases/latest`, сравнивает семантические версии, скачивает APK и
запускает системный установщик. При отсутствии сети или релизов показывает последнюю известную
информацию и не падает.

```bash
gh release list --repo frayedone/frayed
```
