# frayed

> Личное расписание колледжа: пары, погода и транспорт Алматы.

**Репозиторий:** https://github.com/frayedone/frayed

Приложение для одного пользователя: без аккаунтов, входа и облачной синхронизации. Все настройки,
правки расписания и пресеты групп хранятся локально. Сборки публикуются через GitHub Releases и
устанавливаются прямо из приложения. Дизайн и набор экранов повторяют предыдущую версию на Flutter
(`Freya`), но вся логика и UI написаны на Rust.

## Экраны

Три вкладки в нижней панели — **Расписание**, **Погода**, **Транспорт**. Настройки и пресеты
открываются кнопкой в верхней панели расписания.

- **Расписание**: крупное название дня, недельная лента с 7 днями, строка-подсказка о следующей
  паре, погодная подсказка, таймлайн с «рельсой» и живым прогрессом текущей пары. Кнопка колокольчика
  у пары включает локальное напоминание. Отмена дня — отдельной кнопкой.
- **Погода**: большая карточка с градиентом по коду погоды, температурой, состоянием и списком на неделю.
- **Транспорт**: режимы «Остановка» и «Маршрут» — прибытие по остановкам и построение маршрута.
- **Настройки / Пресеты**: уведомления, оформление, сохранённые расписания групп.

Нет ИИ-вкладки, счётчика «дней подряд» и плавающих уведомлений-баджей — в исходном дизайне их нет.

## Возможности

- Недельное расписание группы П4Г, редактирование пар, отмена дня, пресеты групп.
- Локальные уведомления: утренняя сводка и напоминания о парах.
- Погода Алматы через Open-Meteo с русскими подсказками и подсказкой «возьми зонт».
- Статические маршруты и ориентировочное прибытие по остановкам рядом с колледжем.
- Проверка обновлений через GitHub Releases, скачивание APK и установка.

## Архитектура

| Крейт | Назначение |
| --- | --- |
| `frayed-core` | Расписание, отмены и пресеты, даты и русский текст, погодные подсказки, SemVer, локальное хранилище |
| `frayed-net` | Open-Meteo, GitHub Releases, транспорт Алматы |
| `frayed-ui` | Slint-разметка и регистрация шрифта Base 02 |
| `frayed-app` | Точка входа Android, состояние UI, тонкий JNI-слой для уведомлений и установки APK |

### Стек и оформление

- **Rust** (edition 2021), **Slint 1.19** с Android-бэкендом, **cargo-apk2** для APK.
- Палитра: почти чёрный фон `#050607`, карточки `#101316`, границы `#23282F`, акцент — янтарь `#E2A23B`.
- **Base 02 Cyrillic** используется только для заголовков ЗАГЛАВНЫМИ БУКВАМИ с разреженной
  расстановкой ( Slint 1.19 не поддерживает `letter-spacing`, поэтому промежутки добавляет Rust ).
  Основной текст — системный sans-serif с полной поддержкой кириллицы.

## Сборка локально

Нужны Rust, Android SDK (platform 35, build-tools 35.0.0), NDK 27.2.12479018 и JDK 17.

```bash
rustup target add aarch64-linux-android
cargo install cargo-apk2@1.5.0 --locked
cargo apk2 build -p frayed-app --lib --release --target aarch64-linux-android
```

Проверка без Android SDK:

```bash
cargo test --workspace
cargo check --workspace
cargo run -p frayed-app --bin preview   # нужны Build Tools для link.exe
```

## Релизы и обновления

`.github/workflows/release.yml` запускается по тегу `v*` или вручную: устанавливает JDK 17, SDK и NDK,
собирает APK, переименовывает его в `frayed-<версия>.apk` и публикует в GitHub Releases.
Приложение сравнивает версии и предлагает установить обновление.
